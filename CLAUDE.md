# Project Instructions

## Workflow rules

- **Commit regularly.** After every non-trivial, non-experimental change, commit with a descriptive message. Do not accumulate large uncommitted diffs.
- **Update `LAB_NOTEBOOK.md` for every experiment.** Each entry must include:
  - Date
  - What is being tested (the experiment)
  - Motivation (why this experiment matters)
  - Technical details: the actual sequence of commands used to run it, with motivations for parameter choices
  - Outcome and conclusion
